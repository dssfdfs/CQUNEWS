# 仪表盘相关修改说明

## 一、修改概述

本修改包包含以下核心功能的实现：
1. 用户行为记录功能（浏览记录、摘要生成记录）
2. 词云图美化与优化（水平布局、无重叠、紧凑排列）
3. 今日新闻速览修复（只显示当天新闻）
4. 管理员仪表盘数据统计功能

---

## 二、后端修改

### 1. 数据库模型 - models.py

新增 `UserBehavior` 表，用于存储用户行为数据：

```python
class UserBehavior(SQLModel, table=True):
    __tabname__ = "user_behavior"
    id: Optional[int] = Field(default=None, primary_key=True)
    user_id: int = Field(foreign_key="user.id", index=True)
    action_type: str = Field(max_length=32, index=True)  # view, generate, redirect
    target_id: Optional[int] = Field(default=None, index=True)
    extra_data: Optional[str] = Field(default=None)  # 存储分类、标题等额外信息
    timestamp: str = Field(default_factory=lambda: datetime.utcnow().isoformat())
```

### 2. API路由 - routers.py

#### 2.1 今日新闻修复
- 修改 `/api/news` 接口，新增 `today_only` 参数支持
- 使用动态日期获取当天日期，而非硬编码

#### 2.2 新闻查看记录
- 修改 `/api/news/{news_id}` 接口，查看新闻时记录用户行为
- 记录内容包括：用户ID、行为类型(view)、新闻分类、新闻标题

#### 2.3 摘要生成记录
- 修改 `/api/news/{news_id}/summary` 接口，生成摘要时记录用户行为
- 记录内容包括：用户ID、行为类型(generate)、新闻分类、摘要风格、使用模型

#### 2.4 行为记录API
- 新增 `/api/behavior/record` 接口，支持所有用户（含匿名用户）的行为记录

### 3. 管理员API - admin.py

#### 3.1 词云数据API
- `/api/admin/analytics/word-cloud` - 从用户行为数据中提取关键词生成词云
- 优先从行为记录的 `extra_data` 中读取分类信息
- 行为权重：view ×3, generate ×5, redirect ×4

#### 3.2 词语统计API
- `/api/admin/analytics/word-stats` - 获取单个词语的用户行为统计
- 支持从行为记录的 `extra_data` 中读取分类信息

#### 3.3 用户行为统计
- `/api/admin/analytics/user-behavior` - 用户行为数据分析
- `/api/admin/analytics/summary` - 仪表盘数据摘要

## 三、前端修改

### 1. 词云组件 - WordCloud.tsx

#### 布局算法优化
- 强制所有词语水平显示（rotation = 0）
- 使用像素坐标系进行碰撞检测，确保单位统一
- 修正中文字符宽度估算（fontSize × 0.95）
- 多层环形搜索策略，权重高的词语集中在中心

#### 碰撞检测机制
- 基于真实包围盒的碰撞检测
- 无法找到不重叠位置的词语直接跳过，避免强制重叠

#### 视觉效果
- 根据权重决定字体大小（14px - 56px）
- 分类颜色区分（科技、财经、体育等8种颜色）
- 选中状态高亮显示

### 2. 管理员仪表盘 - AdminDashboard.tsx

- 更新使用新词云组件
- 修改饼图配置，移除图例，调整半径和容器高度
- 修复JSX标签不匹配问题

### 3. 新闻详情 - NewsDetail.tsx

- 获取新闻详情时传递Authorization令牌
- "阅读原文"按钮点击时记录 `redirect` 行为

### 4. 新闻预览 - NewsPreview.tsx

- 点击新闻标题跳转原网站时记录 `redirect` 行为
- "查看原文"按钮点击时记录 `redirect` 行为
- 生成摘要的请求添加了 Authorization 令牌
- 添加 `today_only: true` 参数，确保只显示当天新闻

### 5. API层 - news.ts

- 新增 `today_only` 参数支持
- `fetchNewsDetail` 添加 Authorization 令牌传递

### 6. 行为记录工具 - behavior.ts

- 创建通用行为记录工具函数 `recordBehavior` 和 `handleNewsRedirect`
